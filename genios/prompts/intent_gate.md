# 意图识别节点提示词 v1 · 机会文章门控

> **用途**：放在抽取大模型之前。这个节点只回答“文章是否值得进入机会字段抽取”，不负责
> 生成机会字段，也不调用 gateway。
>
> **节点类型**：GeniOS「意图识别」
> **输入**：Start 节点的 `text`（正文）；如租户允许多个输入，可同时传入 `title`，但判定仍以正文为主。
> **温度**：最低；**意图数量**：2。

## 意图定义

### 机会文章

文章中至少有一项当前或未来仍可由学生报名、申请、招募、预约或直接参与的活动/项目，且属于以下四类之一：

- 竞赛
- 学术与学习交流
- 志愿活动与社会实践
- 校园文体活动

“即将举办”“报名中”“面向学生招募”“欢迎参加”等行动信号可以支持这一分类。文章不必同时包含报名链接；只要原文明确存在学生可参与的机会即可。

### 非机会文章

属于以下任一情况：

- 纯新闻、通知转述、工作动态或行政宣传，没有学生可采取的参与行动；
- 表彰、获奖、喜报、成果展示；
- 已结束活动的回顾、总结、报道或复盘；
- 只介绍过去发生的活动，未提供仍可参与的后续机会；
- 招生简章、政策说明等信息性文章，本身不构成上述四类活动机会；
- 无法从原文确认学生可以报名、申请、招募、预约或参与。

边界不清时选择“非机会文章”。不要因为文章出现“活动”“竞赛”“讲座”等词就自动判为机会。

## 节点指令（粘贴到意图识别节点的说明/提示区域）

```
你是校园机会文章门控器。只根据输入文章原文选择一个意图，不做字段抽取，不补充原文没有的信息。

选择“机会文章”：原文至少包含一个当前或未来仍可由学生报名、申请、招募、预约或直接参与的活动/项目，
且类型属于竞赛、学术与学习交流、志愿活动与社会实践、校园文体活动四类之一。

选择“非机会文章”：纯新闻、工作动态、表彰喜报、获奖结果、活动回顾总结、已结束活动、招生或政策说明，
或原文没有明确学生行动机会。边界不清时选择“非机会文章”。

只输出意图分类，不抽取 name、type、时间、链接等机会字段。分类依据必须来自文章本身。
```

## 在 GeniOS 中填写的两个意图

| 意图名称 | 意图描述（直接粘贴） | 下游分支 |
| --- | --- | --- |
| `机会文章` | 学生现在或之后可以报名、申请、招募、预约或参与的竞赛、学术与学习交流、志愿活动与社会实践、校园文体活动。 | 抽取 LLM → `parse_and_validate.py` |
| `非机会文章` | 纯新闻、表彰喜报、获奖结果、活动回顾总结、已结束活动、招生/政策说明，或没有明确学生参与行动的文章。 | `empty_result.py` |

## 输出约定

意图识别节点原生输出的 `classificationName` 用于连线；不要把 `reason` 当作机会字段传给抽取节点。
两个分支最终都必须汇合到同一个 End。非机会分支由 `empty_result.py` 产出统一的空结果：

```json
{
  "ok": false,
  "is_opportunity": false,
  "article_id": "来自 Start",
  "items": [],
  "first_item": null,
  "issues": [],
  "item_count": 0
}
```
